# sdk 0.5.1: public/ moves into src/static/

> Written by: Claude (opus, session 015pj4Rx), 2026-11-25, sharddev
> plan sdk-migrate-static R3

One roll moved this repo with the org's other shard repos:
`wildshard upgrade 0.5.1` ran the 0.5.0 migration (`public/` into
`src/static/`, builds to `out/<slug>`), then `pnpm agents:sync` for the
status hook it adds. The roll checked that every shipped product file is
byte-identical to the same commit built on 0.4.34, except a map whose
inputs moved (its tilesHash, and shard.json naming it), and that
`pnpm check` passes.

The migration leaves old paths in code, tests and map inputs; the
roll moved them in:

- `oxlintrc.author.json`
- `cripts/blender/targets.json`
- `rc/data/map.json`
- `rc/generators/dressing.ts`
- `rc/generators/facets.ts`
- `rc/generators/mapProgram.ts`
- `rc/generators/rocks.ts`
- `rc/generators/rows/whip.ts`
- `est/fixtures/headless/signal-story-run.ts`
- `est/fixtures/native-rapier-file.ts`
- `est/fixtures/sunscar-source-program.ts`
- `est/proof/sunscar-dunes/witness.ts`
- `est/sunscar-fixed-palette.test.ts`

An `assetGlobs` list keeps `public/`: it names mounted files, which
keep their names.
