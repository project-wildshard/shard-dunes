# wildshard check in CI (TS21)

HOW-WE-BUILD TS21. `wildshard check` refused Dunes' far proxy on
sharddev 719c040 ("Far proxy exceeds content caps"), unseen, because
CI ran `pnpm check` and `pnpm build:shards` but never the author's
own check. sharddev 0a8e1e1 (past the 5aa81bd fix) drops the
impostor over the cap and check passes locally in about 25 s. Engine
moves to sharddev's own pin (6f26d0ea) and format to v0.4.9 so the
repo carries one engine and one format.

`ci.yml` now runs `pnpm exec wildshard check . tmp/ci/check` after
each `pnpm build:shards` step, with that step's `if:`. The folder
argument keeps check's output out of `src/shards/<slug>/` until SA24.
